# FAS-Pi Reports

This directory is the durable evidence ledger for the Pi-based FAS project.

## Rules

- Every substantive runtime, audit, testing, implementation, blocker, or release report belongs here.
- Use dated descriptive filenames.
- Preserve old reports; do not rewrite history to hide failures.
- Reports must distinguish VERIFIED, HISTORICAL, REPORTED, UNKNOWN, BLOCKED, and DEFERRED where applicable.
- Include scope, evidence, tests, runtime proof, residual risks, cleanup, commit, and next action where relevant.
- Never store secrets or raw secret-bearing environment output.
