# FAS-Pi Reports

This directory contains dated reports and runtime evidence for the Pi-based FAS line.

Rules:
- Keep project control/state documents in `docs/FAS_PI/`.
- Put dated audits, runtime proofs, test evidence, decisions-from-evidence, and completion reports here.
- Never store secrets or raw secret-bearing environment output.
- Preserve historical reports; do not overwrite evidence to hide failures.
- A report is evidence, not permission to claim a current runtime capability without fresh proof.

Naming:
`YYYY-MM-DD_<subject>.md` for new reports where practical.
