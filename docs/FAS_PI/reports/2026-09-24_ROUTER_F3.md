Status: SHIPPED (core `26f3d323`→`f7c52161`, T17, release 80/80, full

## 1. Problem (from ROUTER_GAP diagnosis)

Exploration trap: the router burned 3 fresh same-provider lanes per turn
(kilo credit-dead pattern); `verified-failure` (consec≥3) unreachable
because ranking prefers unexplored lanes. Rank order alone cannot fix a
turn that walks into a dead provider three times in a row.

## 2. Fix (preference, not exclusion — T15 3+1 bounds preserved)

`runRouterStream` attempt loop now keeps `tried` + `failedProviders`
sets. Each attempt picks the highest-ranked untried candidate whose
provider has not failed THIS turn; if none exists, the highest-ranked
untried candidate regardless of provider. Attempt counting still bounds
actual streams at `maxAttempts`; `planFallback` index follows attempts.
Fatal/non-retryable/budget semantics unchanged — T15 passes unmodified.
